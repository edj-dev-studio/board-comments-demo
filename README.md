# board-comments 데모

이사회 전에 이사별로 안건 관련 과거 발언을 정리해 보내는 시스템(board-comments)의 공유용 데모 화면입니다.

- 가상 샘플 데이터만 들어 있습니다. 인물·회사·안건·이메일은 모두 가상입니다.
- 버튼(제외·포함·승인·머리말·꼬리말 수정·나에게 발송·발송·다시 발송·다시 고치기)은 화면에서만 동작하고 저장되지 않습니다. 메일은 실제로 나가지 않습니다.
- 위 메뉴의 "시스템 소개"에서 업무 흐름 설명서를 볼 수 있습니다.

이 저장소의 파일은 원본 저장소의 `tools/build_demo.py`로 만듭니다. 직접 고치지 않습니다.
